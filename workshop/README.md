# 3D 메이커 체험 공방 — 원페이지 홈페이지

손으로 만드는 특별한 선물. 20~40대 커플과 기념일 체험 고객을 위한 소개용 원페이지 사이트입니다.
HTML 한 장 + SVG 이미지로만 되어 있어 서버나 빌드 도구 없이 그대로 올리면 동작합니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 본체. CSS·JavaScript가 모두 안에 들어 있습니다. |
| `assets/hero.svg` | 히어로 배경 일러스트 |
| `assets/service-*.svg` | 서비스 카드 4종 이미지 |
| `assets/map.svg` | 오시는 길 약도 |
| `assets/og-image.png` | 카카오톡·페이스북 공유용 미리보기 이미지 (1200×630) |

## 보는 방법

`index.html` 을 브라우저로 열면 바로 확인됩니다.
배포는 폴더째 올리기만 하면 됩니다 — Cloudflare Pages, Netlify, GitHub Pages 모두 설정 없이 동작합니다.

## 페이지 구성

1. **히어로** — 전체 화면 배경 + 어두운 오버레이, 메인 카피, 예약 CTA, 스크롤 화살표
2. **체험 소개** — 3D펜 / 굿즈 제작 / 커플 클래스 / 단체 워크숍 카드 4종
3. **우리만의 강점** — 숫자 카운트업 4개 + 강점 3가지
4. **고객 후기** — 자동 재생 캐러셀 (좌우 버튼 · 점 · 모바일 스와이프)
5. **오시는 길** — 약도, 주소·연락처·영업시간·주차 안내
6. **문의하기** — 이름 / 연락처 / 문의 유형 / 내용 폼 + 전화·카톡·인스타 바로가기
7. **푸터** — 상호명, SNS, 사업자 정보, 저작권

## 꼭 바꿔야 하는 내용

아래 항목은 임시값(placeholder)입니다. `index.html` 에서 `TODO:` 로 검색하면 위치를 바로 찾을 수 있습니다.

- **도메인** — `https://example.com/` (canonical, og:url, og:image 3곳)
- **주소** — `대구광역시 ○○구 ○○로 00, 대구 업사이클센터 0층`
- **전화번호** — `053-000-0000` (오시는 길, 바로가기, 폼 완료 메시지, 푸터, 구조화 데이터)
- **카카오맵 링크** — 실제 장소 페이지 URL
- **SNS 주소** — 인스타그램 / 네이버 블로그 / 카카오톡 채널
- **사업자 정보** — 대표자명, 사업자등록번호, 통신판매업신고번호
- **후기 5건과 숫자 4개** — 지금은 예시 문구입니다. 실제 후기·실적으로 교체해 주세요.
  (후기는 `#reviews` 안의 `.slide`, 숫자는 `.count` 의 `data-target` 값)

## 문의 폼 연결하기

현재는 서버 없이 동작하는 상태라, 제출하면 화면에 접수 안내만 표시되고 실제 전송은 되지 않습니다.
실제로 받아보려면 `index.html` 아래쪽 `form.addEventListener('submit', ...)` 안의 주석 부분을 아래처럼 바꾸세요.

```js
// 예: Formspree 사용 시
fetch('https://formspree.io/f/본인폼ID', {
  method: 'POST',
  headers: { 'Accept': 'application/json' },
  body: new FormData(form)
});
```

구글폼, 채널톡, 자체 API 어느 쪽이든 같은 자리에서 연결하면 됩니다.

## 반영된 필수 조건

- 모바일 우선 반응형 (600px · 900px 분기)
- 상단 고정 네비게이션, 스크롤 40px 이후 흰 배경으로 전환
- 900px 미만에서 햄버거 메뉴 (열면 X 아이콘으로 변형, ESC·링크 클릭 시 닫힘)
- 스크롤에 따라 순차 페이드인 (IntersectionObserver, 카드마다 90ms 시차)
- 모든 이미지 `alt` 지정, 아이콘은 `aria-hidden` 처리
- SEO 메타 태그 (title, description, canonical, OG, 트위터 카드, LocalBusiness 구조화 데이터)
- `prefers-reduced-motion` 설정 시 애니메이션 자동 해제
