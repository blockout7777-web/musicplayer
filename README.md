# 🎵 HTML 한 장 뮤직 플레이어

파일 하나만 열면 음악이 흐르는 웹 뮤직 플레이어. 설치도, 서버도, 인터넷 연결도 필요 없습니다.

**데모** — https://music-player-bue.pages.dev

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 본체. 같은 폴더의 mp3를 재생목록으로 읽어 바로 재생합니다. |
| `standalone.html` | 음원 없이 쓰는 버전. 내 컴퓨터의 폴더를 골라 듣습니다. |
| `cover.svg` | 소개용 인포그래픽 이미지 |

`index.html` 은 CSS·아이콘·재생 코드를 모두 안에 담고 있어 밖에서 불러오는 것이 하나도 없습니다.

## 기능

- **앨범아트가 화면 전체의 색을 만듭니다** — 표지 이미지를 크게 흐리게 깔아 배경으로 사용
- **소리에 맞춰 움직이는 스펙트럼** — Web Audio API로 주파수를 실시간 분석해 막대 34개로 표시
- **폴더 통째로 불러오기** — 폴더 선택 또는 창에 끌어놓기, 하위 폴더까지 재귀 탐색
- **ID3 태그 직접 해석** — 제목·가수·앨범 표지를 추출. EUC-KR로 저장된 한글 태그도 자동 판별
- **재생목록 · 검색 · 좋아요 · 반복(전체/한 곡/없음) · 셔플 · 드래그 탐색**

## 조작

| 기능 | 방법 |
| --- | --- |
| 재생 / 정지 | 가운데 원형 버튼, `Space` |
| 이전 / 다음 곡 | `←` `→` |
| 재생목록 | `L` |
| 음악 불러오기 | `O` |
| 구간 이동 | 진행바 클릭 · 드래그 |

## 곡 추가하기

mp3 파일을 `index.html` 옆에 두고, 파일 안의 재생목록에 파일명을 넣습니다.

```html
<script type="application/json" id="playlist">[
  {"file": "mp1.mp3", "title": "", "artist": ""},
  {"file": "mp2.mp3", "title": "", "artist": ""}
]</script>
```

`title` / `artist` 를 비워두면 파일명 또는 ID3 태그에서 자동으로 채워집니다.

## 알아둘 점

**음원 파일은 저장소에 포함되어 있지 않습니다** (`.gitignore` 로 `*.mp3` 제외). 저작권 문제를 피하기 위한 기본값이며, 직접 만든 음원이라면 `.gitignore` 의 해당 줄을 지우고 커밋하면 됩니다.

**`file://` 로 열 때의 제약** — 브라우저는 옆에 놓인 mp3를 교차 출처로 판단해, Web Audio에 연결하면 소리를 무음 처리합니다. 그래서 상대경로 재생 시에는 분석기를 연결하지 않으며 스펙트럼이 표시되지 않습니다. http(s)로 서비스하면 정상 동작합니다.

**자동 재생** — 브라우저 정책상 첫 방문에 소리가 자동으로 나지 않습니다. 화면을 한 번 누르면 재생되도록 처리해 두었습니다.
